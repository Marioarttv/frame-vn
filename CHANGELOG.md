# Changelog

## 0.1.0 — 2026-10-22

Initial independent public release.

- Local React/TypeScript visual novel studio with branching stories, storyboard, scene map, variables, presentation effects, and browser autosave.
- Portable offline HTML games and optional local MP4 rendering.
- Original Mira and Noah examples with six speaking mouth shapes, exact source rest, independent blinks, restrained gaze, source-pixel brows, and head/body motion. Includes source art, generation provenance, and reproducible calibration recipes.
- Optional ElevenLabs/Rhubarb workflow with local credentials, attempt records, and guarded retries. No voice recordings or provider access included.
- MIT licensing for original code and assets; dependency/font notices preserved in relevant distributions.
- CI, contributor guidance, security policy, issue forms, and a screenshot walkthrough.

This is an early release. Each example has one everyday pose; artwork generation is a separate creative process. The local authoring API is intended for one person on their own computer. See the verification record and documented prerequisites before optional voice/video workflows.
